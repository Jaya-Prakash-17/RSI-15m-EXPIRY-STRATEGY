# Reporting

Backtest analysis and trade visualization.

## Files

| File | Purpose |
|---|---|
| `performance.py` | **Analyzer.** Calculates win/loss stats, drawdown, and R-multiples. Generates HTML/JSON reports. |

## Output Formats

1. **HTML Report**: Responsive web page with interactive candlestick charts and performance curves.
2. **JSON Summary**: Machine-readable statistical digest for automated calibration.

## Key Metrics

- Profit Factor
- Max Drawdown
- Average R-multiple
- Win/Loss Ratio
- Monthly Breakdown
