### 2. Continuity Validation Gate
- **<read_first>**: [utils/candle_builder.py]
- **<action>**:
    - Add `_check_continuity(self, symbol, new_dt)` to `CandleBuilder`.
    - If `self.bars[symbol]` is not empty, calculate `delta = new_dt - self.bars[symbol][-1]['datetime']`.
    - If `delta > timedelta(minutes=15)`, log a critical warning and set a `continuity_broken` flag on the builder.
- **<acceptance_criteria>**:
    - `utils/candle_builder.py` contains `def _check_continuity`
    - `self.logger.critical` is called when `delta.total_seconds() > 900`

### 3. Thin Bar / Quality Gate (DATA-01)
- **<read_first>**: [utils/candle_builder.py]
- **<action>**:
    - Harden the existing thin-bar warning (line 99) to also check for "starved" bars (zero volume or ticks < threshold).

- **<acceptance_criteria>**:
    - `closed_candle['is_healthy'] = False` if `ticks < 3` (or configurable threshold).
